# Expenses Planner

- Edit the budget and the year-by-year table; every number updates live. It runs in your browser and sends nothing anywhere.
- **Save** writes `spend_plan.json` where you choose. **Upload** loads a saved `spend_plan.json` back in; **Undo** steps back.
- **Reset** loads the default plan, **Shift+Reset** the older default. Print (landscape) matches the screen.
